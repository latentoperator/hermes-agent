## What changed

`_handle_create` in `tools/kanban_tools.py` previously inherited the parent
worker's workspace (kind + path) for all workspace types, including scratch.
A scratch parent's workspace path — persisted by the dispatcher as
`<workspaces_root>/<parent_task_id>` — leaked to every child via
`kanban_create`, causing sibling collisions when the dispatcher tried to
mount the same concrete directory for multiple child workers.

The fix gates workspace inheritance on the parent's `workspace_kind` being in
`{"dir", "worktree"}`, deliberately excluding scratch. The variable rename
(`_inherit_workspace` → `_inherit_persistent_workspace`) and updated
docstring accurately reflect this narrowed intent.
